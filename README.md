# f1Bidda — F1 Race Strategy Analytics

A deep interactive Formula 1 race strategy, tire degradation, and telemetry analytics platform for fans and analysts.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd f1Bidda
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
